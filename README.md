# Influencer Campaign Performance Tracker

## Project Overview
The Influencer Campaign Performance Tracker is a data analytics project designed to analyze influencer marketing campaigns and evaluate their performance across different platforms. It helps understand campaign reach, engagement, spending, revenue, and return on investment (ROI) through data analysis and interactive Power BI dashboards.

## Objectives
- Analyze influencer marketing campaign performance.
- Compare performance across social media platforms and campaigns.
- Track engagement, reach, spending, revenue, and ROI.
- Create interactive dashboards to support data-driven decisions.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Power BI
- Excel / CSV for data handling

## Dataset
The project uses a synthetic dataset generated using Python and NumPy for campaign performance analysis. The dataset contains approximately 1,000,000 rows and 30 columns.

## Project Workflow
1. Generate and load the campaign dataset.
2. Explore the data using Python and Pandas.
3. Check and handle missing values and duplicate records.
4. Clean, filter, group, and analyze the data.
5. Calculate key performance indicators, including ROI.
6. Export the cleaned data for Power BI.
7. Build interactive dashboards to visualize campaign performance.

## Key Performance Indicators (KPIs)
- Campaign reach
- Engagement metrics
- Campaign spend
- Revenue generated
- Return on Investment (ROI)

### ROI Formula
ROI = (Revenue - Spend) / Spend

ROI can be multiplied by 100 to express it as a percentage.

## Power BI Dashboard
The dashboard is organized into four pages:
- Executive Overview
- Influencer Performance
- Platform Performance
- Financial Performance

Interactive visuals and slicers help users explore and compare campaign results.

## Key Outcomes
- Organized and analyzed a large campaign dataset.
- Identified useful campaign and platform performance metrics.
- Visualized financial and engagement indicators.
- Created interactive dashboards to make campaign analysis easier.

## Skills Demonstrated
Python, Pandas, NumPy, Data Cleaning, Exploratory Data Analysis (EDA), KPI Analysis, Data Visualization, Power BI, Dashboard Development.

## Note
This project focuses on data cleaning, exploratory analysis, KPI calculations, and visualization. It does not include a machine-learning prediction model.
